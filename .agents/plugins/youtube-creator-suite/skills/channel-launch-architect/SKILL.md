# Channel Launch Architect Skill

Use this workflow to design, structure, and execute a zero-to-one launch for a brand-new YouTube channel, engineered to trigger algorithmic momentum and immediate monetization before reaching 1,000 subscribers.

## Procedure

### 1. Market Research & Strategic Positioning
Call `blueprint_new_channel`:
- Pass `niche` and optional `creator_strengths` (e.g. `'ai coding agents'`, `'notion productivity for freelancers'`).
- Extract the target audience pain points, primary competitor weaknesses, recommended channel name angles, and monetization strategy.

### 2. Design the 5-Video Algorithmic Binge Playlist
Call `design_binge_playlist`:
- Pass `core_topic` and `video_count=5`.
- Structure the serialized video roadmap from Video 1 (Quick Win) to Video 5 (Capstone).
- Ensure each video ends with the specific cliffhanger bridge script and end-screen card pointing to the subsequent video to maximize Session Watch Time.

### 3. Generate High-Retention Script Outlines
Call `generate_retention_script_outline`:
- Pass `video_title_or_topic` for the launch video.
- The tool automatically finds the #1 competitor, transcribes their first 60 seconds to model the hook, and mines viewer comments for objections.
- Review the 7-beat script outline (Hook -> Problem Stakes -> Step-by-Step Deliverables -> Cliffhanger Bridge).

### 4. Build Complete SEO Upload Metadata Packs
Call `generate_seo_metadata_pack`:
- Pass `video_topic_or_working_title` and `target_audience`.
- Extract real competitor tags from currently ranking videos.
- Assemble: 3 mobile-optimized titles, search-optimized description, timestamped chapters, high-traffic tags, and a pinned comment engagement question.

### 5. Construct the Sub-1,000 Subscriber Monetization Funnel
Call `generate_monetization_offers`:
- Pass `niche` and `target_audience`.
- Deploy the 3-tier architecture:
  - **Tier 1 (Free)**: Cheatsheet / template lead magnet to build an email list.
  - **Tier 2 ($19–$47)**: Digital starter toolkit / system for immediate cash flow.
  - **Tier 3 ($250–$1,000+)**: 1-on-1 audit or done-with-you implementation.
- Embed the standardized description box template into all launch uploads.

### 6. Build the Pre-Launch Community Tab Strategy
Call `analyze_community_posts`:
- Pass `niche_or_channel` and `target_goal="growth"`.
- Schedule interactive polls and quizzes 48 hours prior to video launch to warm up YouTube's home feed distribution to non-subscribers.
