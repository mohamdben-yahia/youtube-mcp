# YouTube Strategic & Algorithmic Rules

When executing YouTube research, script writing, title/thumbnail ideation, or channel strategy, adhere to the following core principles:

1. **100% Empirical Evidence Over Guesses**:
   - Always base recommendations on live YouTube Data API numbers (view-to-subscriber ratios, outlier multipliers, actual competitor video age).
   - Never use placeholder tags or synthetic benchmarks when live competitor queries are available.

2. **Session Watch Time Over Individual Views**:
   - The YouTube algorithm prioritizes viewers staying on the platform.
   - Always connect videos into binge playlists using cliffhanger bridges, playlists, and end-screen recommendations.

3. **The First 60-Second Hook Rule**:
   - 50% of viewer drop-offs occur within the first 60 seconds.
   - Forbid prolonged channel introductions ("Hey guys, welcome back to the channel, don't forget to like and subscribe").
   - Mandate an immediate hook: Problem Identification -> Emotional Stake -> Concrete Value Proposition.

4. **Packaging Before Production**:
   - A video concept should never be scripted or filmed until at least 3 high-CTR titles (with curiosity gap or threat avoidance) and 3 contrasting thumbnail concepts have been validated.

5. **Sub-1,000 Subscriber Monetization**:
   - Never tell creators to wait for AdSense (YPP requires 1,000 subscribers and 4,000 watch hours).
   - Implement the 3-tier monetization funnel immediately: Free Lead Magnet ($0) -> Digital Product ($19–$47) -> High-Ticket Consulting/Implementation ($250–$1,000+).
