# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

The YouTube MCP Server team takes the security of our software and users seriously.

If you believe you have discovered a security vulnerability in this project (such as token leakage, authentication bypass in the SSE middleware, or API key exposure risks):

1. **Do NOT publicly disclose the issue** in GitHub issues or discussions.
2. Please send a confidential report via email to **benyahiamohamd@gmail.com** with:
   * A clear description of the vulnerability.
   * Steps or scripts to reproduce the issue.
   * Potential impact and any suggested mitigations.
3. You will receive an initial response acknowledging receipt within **48 hours**.
4. We will coordinate with you on fixing and testing the vulnerability before a public patch release is deployed.

Thank you for helping keep the open-source AI community safe!
